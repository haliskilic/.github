# .github

Default community health files for all repositories of [@haliskilic](https://github.com/haliskilic):

- [`.github/FUNDING.yml`](.github/FUNDING.yml) — the **♥ Sponsor** button ([GitHub Sponsors](https://github.com/sponsors/haliskilic))
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — how to contribute, including the one-time
  [Contributor License Agreement](https://gist.github.com/haliskilic/7a7fdcd355f54d1db6943959d7b76823)

A repository's own file of the same type takes precedence over these defaults.
